# AISKG Section 2 — post-extraction analysis and validation

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/romenmeitei/AISKG_02_Framework/blob/main/Mushroom_KG_Complete_Reproducibility_Pipeline_v2.ipynb)

This repository contains the canonical deterministic workflow for the
manuscript-facing post-extraction analyses. The upstream literature retrieval,
topic modelling, and ontology-guided extraction workflow is available in
[AISKG Section 1](https://github.com/romenmeitei/AISKG_01_Framework).

## Canonical entry point

`Mushroom_KG_Complete_Reproducibility_Pipeline_v2.ipynb`

The notebook uses one checksum-verified input ZIP and generates one complete
results ZIP. The default route does not call live bibliographic APIs, retrain
BERTopic, download biomedical NLP models, or depend on external Excel links.

## Analyses reproduced

1. Input-integrity and reviewer-workbook checks.
2. Corpus size, domain distribution, annual trends, chi-square statistics, and
   Shannon diversity.
3. Semantic-edge aggregation, evidence filtering, centralities, Louvain
   communities, and modularity.
4. Temporal graph metrics for 2000–2009, 2010–2019, and 2020–2025.
5. Outcome-aware pathway refinement and score–stability regression.
6. Independent blinded validation of 300 entities, 220 relations, and 52
   pre-refinement pathways, including agreement, Cohen's kappa, Gwet's AC1,
   bootstrap intervals, adjudication, and Wilson intervals.
7. Candidate-level entity and relation benchmarks, frozen scispaCy recovery,
   sentence co-occurrence, type-pair rules, and McNemar analysis.
8. A human-audited 150-sentence held-out entity benchmark.
9. Strict, ontology-aware, AI-assisted-adjudicated, and conservative held-out
   relation analyses.
10. Conventional co-occurrence network construction and semantic-pair overlap.
11. Toxin-class representation, HHI, normalized entropy, composite scores, and
    research-priority ranking.
12. A manuscript-consistency audit and 94 fixed-result checks.

## Important interpretation rules

### Two separate 52-pathway datasets

The 11/52 expert-validation result concerns pre-refinement sampled candidate
pathways. The pathway score–stability analysis uses a separate post-refinement
outcome-aware set of 52 clean pathways. They must not be described as the same
endpoint.

### S4 review provenance

The S4 second review is AI-assisted and is a sensitivity/adjudication audit,
not independent dual-human inter-rater validation. Independent blinded
validation uses the separate Expert A, Expert B, and adjudicator workbooks.

### Corrected audited values

- Pair-set Jaccard: `38 / (191 + 86 − 38) = 0.159`.
- Relation correctness/exact corrected triple: `163/220 (74.1%)`.
- Audited corrected entity reference set: 294 concepts.
- Relation-bearing gold set: 184 triples.
- Sentence co-occurrence baseline: precision 0.800, recall 0.540, F1 0.645.

See `MANUSCRIPT_CORRECTIONS_REQUIRED.md` for the complete audit trail.

## Local execution

```bash
unzip Mushroom_KG_Reproducibility_Inputs_v2.zip -d extracted_inputs
python pipeline_core.py \
  --input-dir extracted_inputs/data \
  --output-dir outputs
```

The script searches recursively for the checksum manifest, so a Section 1
bridge ZIP may also be extracted and supplied.
